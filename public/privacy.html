Privacy di Printopus

Ultimo aggiornamento: 11 novembre 2026

Printopus è un sito statico e open source per progettare oggetti da stampare in 3D. Non ha un server proprio, non chiede di creare un account, non usa cookie di profilazione né strumenti di statistica.

Dati salvati sul tuo dispositivo

Progetti, modelli importati, stampante, filamenti e impostazioni restano nel tuo browser (IndexedDB e localStorage). Anche le chiavi API e i token di collegamento ai servizi cloud sono salvati solo lì. Puoi cancellare tutto pulendo i dati del sito nel browser.

Servizi esterni, solo se li scegli tu

  • Assistente AI (Anthropic Claude, Google Gemini, OpenAI): il browser invia direttamente al servizio scelto le tue richieste e i dati del progetto necessari a rispondere, con la tua chiave. Valgono le condizioni del servizio scelto; per esempio, nel piano gratuito Google può usare i contenuti per migliorare i propri prodotti.
  • Connettore per Claude: se colleghi un progetto alla chat di Claude, il progetto viene copiato in un servizio su Cloudflare, legato a un codice casuale, e viene cancellato in automatico dopo 7 giorni.
  • Backup nel cloud (Dropbox, Google Drive): i progetti vengono salvati nel tuo account. Su Dropbox l'app vede solo la propria cartella in Apps; su Google Drive solo i file creati dall'app (permesso drive.file). Printopus non legge né conserva altri file e non condivide questi dati con nessuno. Puoi scollegare il servizio quando vuoi dalle impostazioni o dal tuo account Dropbox/Google.

Uso dei dati di Google

L'uso e il trasferimento delle informazioni ricevute dalle API di Google rispettano le Google API Services User Data Policy, compresi i requisiti di uso limitato.

Hosting

Il sito è pubblicato su GitHub Pages, che può registrare dati tecnici come l'indirizzo IP per sicurezza e funzionamento, secondo l'informativa di GitHub.

Contatti

Per domande apri una segnalazione su github.com/Marketto/tako-maker/issues.

Printopus privacy policy

Last updated: 11 November 2026

Printopus is a static, open-source website for designing 3D-printable objects. It has no server of its own, requires no account, and uses no tracking cookies or analytics.

Data stored on your device

Projects, imported models, printer, filaments and settings stay in your browser (IndexedDB and localStorage). API keys and cloud connection tokens are stored only there too. You can delete everything by clearing the site data in your browser.

External services, only if you choose them

  • AI assistant (Anthropic Claude, Google Gemini, OpenAI): your browser sends your requests and the project data needed to answer directly to the chosen service, using your key. That service's terms apply; for example, on the free tier Google may use content to improve its products.
  • Claude connector: if you link a project to the Claude chat, the project is copied to a service on Cloudflare, tied to a random code, and deleted automatically after 7 days.
  • Cloud backup (Dropbox, Google Drive): projects are saved in your own account. On Dropbox the app only sees its own folder in Apps; on Google Drive only the files it created (drive.file scope). Printopus does not read or keep any other files and does not share this data with anyone. You can disconnect at any time from the settings or from your Dropbox/Google account.

Use of Google data

Printopus's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Hosting

The site is hosted on GitHub Pages, which may log technical data such as IP addresses for security and operation, under GitHub's privacy statement.

Contact

For questions, open an issue at github.com/Marketto/tako-maker/issues.
